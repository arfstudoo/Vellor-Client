# Vellor Client

Бесплатное приложение для подключения к VPN и работы с прокси-серверами на базе sing-box и xray для Windows и Android.

Клиент представляет собой независимую графическую оболочку. Приложение не предоставляет собственных серверов: пользователь подключает свой сервер или подписку любого провайдера.

## Возможности

* Протоколы: VLESS (Reality, Vision), VMess, Trojan, Shadowsocks, Hysteria, Hysteria 2, TUIC, WireGuard, SOCKS5.
* Подписки: автоматический импорт по ссылке, поддержка форматов Base64 и Clash YAML.
* Режимы работы:
  * TUN: системный сетевой адаптер с полным перехватом трафика через драйвер Wintun / Android VpnService.
  * System Proxy: маршрутизация через системный прокси без создания виртуального сетевого интерфейса.
* Маршрутизация:
  * Прямой доступ для российских сайтов и сервисов в обход прокси.
  * Раздельное туннелирование (Split Tunneling) для выбранных программ.
  * Защита от утечек DNS.
* Интерфейс: темная тема, отображение времени подключения, пинг серверов, поиск и сортировка, работа в системном трее Windows.

## Установка

### Windows
Установочный файл: `VellorClient_Setup.exe`.
Установка выполняется в каталог текущего пользователя и не требует прав администратора для запуска базовых функций (для режима TUN требуются права администратора).

### Android
Готовые пакеты:
* `vellor_client_arm64.apk` для современных смартфонов (ARM64).
* `vellor_client_universal.apk` универсальная сборка для всех архитектур.

## Сборка из исходников

Требования:
* Flutter SDK 3.13+ / Dart 3.0+
* Для сборки под Windows: Visual Studio 2022 (C++ desktop development)
* Для сборки под Android: Android SDK 35+, NDK 28+

Сборка Windows:
```bash
flutter pub get
flutter build windows --release
```

Сборка Android APK:
```bash
flutter pub get
flutter build apk --release --split-per-abi
```
